delonix manifest

Trabalhar num manifesto sem tocar no host — render com defaults preenchidos.

Work on a manifest without touching the host — render with defaults filled in.

manifest render faz o round-trip de um documento pelo seu struct tipado e imprime o YAML completo, com os #[serde(default)] materializados — o equivalente a um kubectl --dry-run=client -o yaml. Não aplica nada; é a forma de ver o que um kind: escrito à mão vai realmente ficar depois de o motor o ler.

manifest render round-trips a document through its typed struct and prints the full YAML with #[serde(default)]s materialized — the equivalent of a kubectl --dry-run=client -o yaml. It applies nothing; it is how you see what a hand-written kind: will actually become once the engine reads it.

Saída real do binário (em inglês).
Real output of the binary (English).
Usage: delonix manifest <COMMAND>

Commands:
  render    Print the manifest as the engine will read it, with defaults filled in
  schema    The JSON Schema, generated from the Rust types (ADR-0007)
  validate  Check a manifest against the schema, the references and the graph
  help      Print this message or the help of the given subcommand(s)

Options:
  -h, --help
          Print help (see a summary with '-h')

COMMAND MAP:
  manifest  validate · render · schema

EXAMPLES:
  # everything here is host-free — it reads the file, not the machine
  delonix manifest validate -f delonix-manifest.yaml
