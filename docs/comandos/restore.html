delonix restore

Repõe um recurso a partir de um arquivo do `delonix backup`.

Desempacota para uma pasta de trabalho ANTES de tocar em seja o que for — um arquivo truncado custa então zero, ao passo que desempacotar por cima dos dados vivos destruía-os sem ter nada para repor. Recusa-se enquanto o recurso estiver a correr (com --force pára-o, repõe, e volta a arrancá-lo). Se o recurso já não existir, é recriado: a imagem volta a descarregar-se, o rootfs é preparado como o run faria, e o registo volta ao sítio. Os volumes vêm primeiro e o recurso depois — ao contrário, um container arrancava contra um volume vazio.

📄 Implementação real em Rust: cmd/rbackup.rs

Usage: delonix restore [OPTIONS] <KIND> <ARCHIVE>

Arguments:
  <KIND>
          What to restore
          
          [possible values: container, pod, vm, stack]

  <ARCHIVE>
          The archive: a path, or the bare name of one in `--from`

Options:
      --from <FROM>
          Where to look for the archive when it is named rather than a path
          
          [default: .]

      --l18n <en|pt>
          Output language: `en` (default) or `pt` (Portuguese, pt_AO). Also settable via `$DELONIX_L18N`. Global — works before any subcommand

      --force
          Restore even when the live resource has data that is not in the archive

      --dry-run
          Print what would be restored, without touching anything

  -h, --help
          Print help (see a summary with '-h')

EXAMPLES:
  # put the data back (refuses while it is running — that would corrupt it)
  delonix restore container container-db-20260811-205312.tar.gz

  # stop it, restore, start it again
  delonix restore container ./container-db-20260811-205312.tar.gz --force

  # from the directory the backups live in, by bare name
  delonix restore stack stack-loja-20260811-210000 --from /srv/backups

  # what it would touch, without touching it
  delonix restore vm vm-dev-20260811-210109.tar.gz --dry-run

ExemplosExamples

Repor os dados (recusa enquanto estiver a correr)
delonix restore container container-db-20260811-205312.tar.gz
Parar, repor e arrancar de novo
delonix restore container ./container-db-20260811-205312.tar.gz --force
Pelo nome nu, a partir da pasta onde os backups vivem
delonix restore stack stack-loja-20260811-210000 --from /srv/backups
O que tocaria, sem lhe tocar
delonix restore vm vm-dev-20260811-210109.tar.gz --dry-run
