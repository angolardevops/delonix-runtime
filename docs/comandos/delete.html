delonix delete

Remove recursos por Kind e nome — a forma genérica de dez `rm`s.

Remove resources by Kind and name — the generic form of ten `rm`s.

Sem nome, recusa-se em vez de remover todos os recursos do Kind: um argumento em falta é muito mais vezes um erro de escrita do que uma intenção, e este verbo não tem uma segunda oportunidade para perguntar. O Kind resolve-se pelo mesmo registo que api-resources imprime, por isso pods/pod/po são a mesma pergunta.

With no name it REFUSES rather than removing every resource of the Kind: a missing argument is far more often a typo than an intention, and this verb doesn't get a second chance to ask. The Kind resolves through the same registry api-resources prints, so pods/pod/po are the same question.

EXAMPLES:

  delonix delete pod api

  delonix delete pods
