This is the DECLARED view — every host assumed complete. `delonix provider ls` measures the same declarations on a real host and turns a declared yes the host cannot honour into `unavailable-on-host`. States: `supported` (implemented and exercised — the evidence names a battery check `check:`, a section `e2e:`, a chaos scenario `chaos:`, a unit test `test:` or a live test `live:`), `partial` (implemented with a written limit, or without live proof), `unsupported-by-provider`, `requires-external-component`, `not-implemented`. See ADR-0050.

The denominator leaves out `unsupported-by-provider` and `requires-external-component`: those say the cell can never be filled by that provider, and counting them would reward staying silent about what a provider is not.
